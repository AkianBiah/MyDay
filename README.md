# 🌸 My Day 🌸

A Kawaii-themed Android task manager that keeps your day organized with a touch of sweetness! ✨

## ✨ Description
My Day is a professional yet adorable task management application designed for those who love a Kawaii aesthetic. It integrates real-time weather and time tracking to help you plan your day beautifully.

## 🌟 Key Features
- 🎨 **Dynamic Theme:** A vibrant Pink and Purple theme that adapts to your style.
- ✅ **Task Management:** Organize your to-dos with cute heart-shaped icons and smooth interactions.
- ⏰ **Real-time Clock & Calendar:** Always stay on track with a built-in cute clock and calendar display.
- ☁️ **Weather Integration:** Stay prepared with real-time weather updates powered by Retrofit.

## 🛠 Tech Stack
- **Language:** [Kotlin](https://kotlinlang.org/)
- **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Navigation:** [Navigation 3](https://developer.android.com/jetpack/compose/navigation)
- **Layout:** Material Adaptive
- **Networking:** [Retrofit](https://square.github.io/retrofit/)
- **Asynchronous:** [Coroutines](https://kotlinlang.org/docs/coroutines-overview.html)

## 🚀 How to Run
1. Clone the repository (if applicable) or open the project folder in **Android Studio (Ladybug or newer)**.
2. Sync the project with Gradle files.
3. Ensure you have an Android device or emulator running API 31+ for the best experience (Dynamic Color support).
4. Build and run the `:app` module.

## 🎀 Process of Creation
The development of My Day followed a structured and aesthetic-driven approach:
1. **Theme:** Established the Kawaii design tokens, including the dynamic Pink/Purple color palette and custom typography.
2. **Navigation:** Implemented a modern navigation structure using Navigation 3 and Material Adaptive for seamless screen transitions.
3. **Tasks:** Developed the core task management logic, focusing on intuitive UX and cute visual feedback.
4. **Weather:** Integrated external weather data using Retrofit to provide real-time context to the user's day.
